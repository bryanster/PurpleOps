PurpleOps — the user interface is not in this binary

The API is running and answering at /api/v1; only the web app is missing. This binary was built without the spa build tag, so it carries this page instead of web/dist.

To build the real thing:

make build   # builds the SPA, then the binary with -tags spa

Or, while working on the frontend, run Vite and let it proxy the API to this server:

npm --prefix web run dev   # http://localhost:5173
